
# Predicción de Consumo de Energía en Edificios 🏢⚡

Este proyecto aplica técnicas de Machine Learning para predecir la **carga térmica de calefacción y refrigeración** de edificios, basándose en características arquitectónicas como:

- Orientación del edificio
- Relación de superficie de ventanas
- Grosor de paredes, techos y techos
- Altura y número de pisos

## 📊 Dataset
El dataset proviene de la Universidad de California en Irvine (UCI):
https://archive.ics.uci.edu/ml/datasets/Energy+efficiency

Incluye 8 variables de entrada (features) y 2 salidas:
- **Heating Load (Y1)**
- **Cooling Load (Y2)**

## 🧠 Objetivo
Construir un modelo de regresión que prediga el consumo energético de calefacción y refrigeración según las características arquitectónicas del edificio.

## ⚙️ Herramientas utilizadas
- Python 3
- Pandas, Numpy
- Matplotlib, Seaborn
- Scikit-learn
